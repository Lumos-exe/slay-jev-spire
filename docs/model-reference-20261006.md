## 参考决策入口

`choice_payload()` 是 Jev 与外部模型共用的纯请求构造函数，生成相同的状态、指令、选项和引用映射。
外部入口复用最终最多 32 项、队列执行、原生合法性和事务回执，不提供候选评分或额外后备动作。
它不调用 Jev，也不从另一个模型的选择中投票；最终只接受一次明确的候选 ID。

启动参考运行：

```powershell
tools/launch_jev.ps1 -DecisionMode external -StartNew -Seed 1062026403 -MaxDecisions 1000
```

完整请求留档在 `logs/live/decisions/requests/<request_id>.json`；当前请求由只追加的
`events.jsonl` 索引，使用 `current_request()` 或 `tools/reference_io.py read` 读取。
模型应读取其中 `payload.state` 和 `payload.question`，再提交：

```powershell
.venv/Scripts/python.exe tools/submit_decision.py --request-id <当前请求UUID> --choice <候选ID> --model codex-session --reason "模型自己的决策依据"
```

仅接受当前等待请求的候选 ID；摘要哈希、请求 UUID 和不可变请求留档共同核对。过期请求、游戏命令文本、
候选外 ID 或缺失模型归属均拒绝。写回复不会直接执行命令；控制器仍刷新状态并通过原生执行流程。
等待上限为 600 秒，暂停或超时停止此次选择，不退回单张出牌或 Jev。运行日志明确记录 external 与模型归属。

这个入口可让当前 Codex 模型进行参考实战，也可供独立推理模型适配器提交结果。
参考模型走远只证明候选与执行流程有能力支撑该次打法，不能证明 Jev 已改善或无人值守模型服务已经接好。
